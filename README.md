# Muni University Equipment Borrowing and Return Tracker (Group 8)

## Overview
This web application was built as part of the ITM 1131 Web Application Development course at Muni University. It provides a simple, browser-based system for students and staff across university laboratories and ICT departments to check equipment availability, submit borrowing requests, and track returns without needing a complex backend database.

## Key Features
- Equipment Catalog: Displays sample items like laptops, multimeters, and projectors with categories, locations, and real-time status.
- Search & Filter: Instantly filter equipment by type, condition, or availability.
- Borrowing Form: Validated request form with automatic reference number generation and status feedback.
- Smart Calculations: Automatically computes expected return dates and highlights overdue items.
- Responsive Design: Built using HTML5, CSS Flexbox/Grid, and vanilla JavaScript to work seamlessly across mobile, tablet, and desktop screens.

## Technical Stack
- HTML5: Semantic markup, accessible labels, and keyboard-friendly controls.
- CSS3: Custom external stylesheet with global box-sizing: border-box, Flexbox, and CSS Grid.
- Vanilla JavaScript: Modular functions handling search, filtering, date calculations, and form validation states.

## Limitations & Scope
- Operates entirely on client-side sample data and browser storage.
- Does not include a persistent backend database, user authentication system, or online payment integration.
